# =============================================================================
# CONTEXT
# =============================================================================

# Framework positioning:
Context: Armature targets Node.js developers moving to Rust
Context: Armature provides batteries-included enterprise features
Context: Performance is benchmarked against Actix-web, Axum and Rocket; see the comparisons page for current numbers
Context: DX is similar to NestJS/Angular patterns
Context: Pre-1.0: evaluate it for your use case and pin a minor version; breaking changes are expected before 1.0

# Key differentiators:
Context: Built-in dependency injection (rare in Rust ecosystem)
Context: Decorator-style macros for familiar DX
Context: Module system for code organization
Context: Comprehensive auth (JWT, OAuth2, SAML, 2FA, Passwordless)
Context: Cloud provider SDKs (AWS, GCP, Azure) with DI integration
Context: Serverless deployment support (Lambda, Cloud Run, Azure Functions)

# =============================================================================
# CODE GENERATION
# =============================================================================

# When generating Armature code:
CodeStyle: Use `armature::prelude::*` for imports
CodeStyle: Apply #[injectable] to services
CodeStyle: Apply #[controller("/path")] to controllers
CodeStyle: Use #[get], #[post], #[put], #[delete], #[patch] for routes
CodeStyle: Use #[module(...)] to wire providers and controllers
CodeStyle: Return Result<Json<T>, Error> from handlers
CodeStyle: Use HttpRequest for accessing params, body, headers

# Example pattern:
```rust
use armature::prelude::*;

#[injectable]
#[derive(Default, Clone)]
struct MyService;

#[controller("/api/resource")]
#[derive(Default, Clone)]
struct MyController;

impl MyController {
    #[get("/:id")]
    async fn get(req: HttpRequest) -> Result<Json<T>, Error> {
        // handler implementation
    }
}

#[module(providers: [MyService], controllers: [MyController])]
#[derive(Default)]
struct AppModule;
```
